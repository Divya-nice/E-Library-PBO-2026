# E-Library - Sistem Manajemen Perpustakaan Digital

Proyek Final PBO 2026 (Konsep MVC + Tkinter).

## Tim & Pembagian Tugas
- **Divya** - PM, Controller (main.py), Integrasi MVC, Testing, GitHub, Merge, Presentasi.
- **Lunny** - View/UI, seluruh tampilan Tkinter, Treeview, Menu Bar, Layout.
- **Haliza** - Model, SQLite, CRUD Database, Laporan, Dokumentasi, README.

## Struktur Folder
```
E-Library/
  assets/
  database/library.db
  model.py
  view.py
  main.py
  README.md
  requirements.txt
```

## Cara Menjalankan (tahap UI)
```bash
python view.py
```

## Branch Git
```
main        -> versi final
develop     -> tempat merge semua fitur
feature/view-ui     -> Lunny
feature/model       -> Haliza
feature/controller  -> Divya
```
Jangan push langsung ke main. Semua perubahan merge ke develop dulu.

## Konsep OOP
- Encapsulation, Inheritance (Frame Tkinter), Polymorphism.
